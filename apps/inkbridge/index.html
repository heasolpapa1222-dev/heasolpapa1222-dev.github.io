InkBridge는 종이 일기·플래너와 휴대폰을 잇는 앱입니다. 앱에서 속지를 만들어 인쇄하고, 손으로 쓴 페이지를 스캔하면 날짜별로 정리되고 글자로도 검색됩니다.

⬇ APK 다운로드 설치 방법 보기

Android 8.0 이상 · 웹에서 직접 설치 (Google Play 준비 중)

🖨️

① 속지 만들기

줄지·원고지·세로쓰기 속지를 앱에서 꾸며 바로 인쇄합니다.

✍️

② 손으로 쓰기

펜으로 편하게 씁니다. 기록은 여전히 종이 위에.

📷

③ 스캔해서 보관

찍으면 날짜에 맞춰 저장되고, 손글씨도 글자로 검색됩니다.

features

이런 걸 할 수 있어요

📅 오늘의 기록부터

  • 오늘 일기만 먼저 — 앱을 열면 오늘 날짜 기록이 바로 보입니다
  • 전체 보기 — 버튼 하나로 모든 기록을 한눈에
  • 달력 — 기록이 있는 날을 표시하고, 날짜를 눌러 이동
  • 폴더 — 일기를 끌어다 놓아 주제별로 묶기
  • 완료 표시 · 알림 — 다 쓴 일기 체크, 다시 볼 날 알림

📷 스캔과 검색

  • 문서 스캔 — 페이지를 반듯하게 펴고 선명하게 보정
  • QR 양식 인식 — 인쇄한 속지의 QR로 어떤 양식인지 자동 인식
  • 손글씨 인식(OCR) — 쓴 내용을 글자로 바꿔 키워드 검색
  • 갤러리에서 불러오기 — 이미 찍어 둔 사진도 일기로

🖋️ 속지 편집기

  • 원고지 · 세로쓰기 속지 — 글자가 칸에 맞춰 들어갑니다
  • 한글 궁체 · 흘림체 — 손글씨 느낌의 글꼴로 타이핑
  • 문구 고정 · 체크박스 — 자주 쓰는 할 일 목록을 속지에
  • 스탬프 — 내 이미지로 도장 만들어 찍기
  • 속지 저장 · 인쇄 — 만든 양식을 저장해 두고 다시 인쇄

💾 보관과 내보내기

  • 백업 내보내기 — 기록을 폴더째 내 저장소로
  • 기기 안 처리 — 스캔과 손글씨 인식은 휴대폰 안에서 합니다

how to install

설치 방법

  1. 1

    휴대폰 브라우저(Chrome, 삼성 인터넷)로 이 페이지를 열고 APK 다운로드를 누릅니다.

  2. 2

    "이 유형의 파일은 기기를 손상시킬 수 있습니다" 안내가 나오면 다운로드를 누릅니다. 웹에서 받는 모든 앱에 나오는 기본 안내입니다.

  3. 3

    받은 파일을 열면 "출처를 알 수 없는 앱 설치" 허용을 묻습니다. 설정을 눌러 지금 쓰는 브라우저에 이 출처 허용을 켜고 뒤로 돌아옵니다.

  4. 4

    설치를 누릅니다. Play 프로텍트가 확인 창을 띄우면 무시하고 설치(또는 설치)를 고릅니다.

업데이트할 때

새 버전이 나오면 앱을 열 때 "업데이트를 해야 합니다" 화면이 나옵니다. 업데이트를 누르면 새 파일을 받아 설치 화면이 열리고, 설치가 끝나면 열기를 누르면 됩니다. 처음 한 번은 InkBridge에 "이 출처 허용"을 켜 달라는 설정 화면이 나옵니다. 기존 기록은 그대로 유지됩니다.

앱을 지우고 다시 설치하면 기록이 사라지니, 그 전에 꼭 백업 내보내기를 해 주세요.

MathKeyboard 메모가 넘어오지 않으면

키보드를 InkBridge보다 먼저 설치했다면, InkBridge 설치 후 MathKeyboard(LaTeX)를 한 번 업데이트하거나 다시 설치해 주세요.
